- Прогон запросов через API (FastAPI + Ollama)
- Сбор ответов LLM
- Сравнение с эталоном
- Метрики:
  - Faithfulness (ответ основан на контексте, нет галлюцинаций)

  - Correctness (фактическая правильность vs эталон)
  - Citation accuracy (ссылки соответствуют источникам)
  - Refusal correctness (правильно ли система отказывается при недостатке контекста)
