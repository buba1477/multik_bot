## Рекомендации

### 1. Увеличить probe до 500-1000 символов

```
probe = stripped[:800]   # вместо 200
```

**Плюсы:** решает ~93% случаев категории "Прочие".
**Риски:** более длинный probe может случайно совпасть на нескольких страницах длинного документа (117-ФЗ: 1867 страниц).
**Компенсация:** брать первое совпадение (самую раннюю страницу) - это консервативно и обычно корректно, т.к. чанк редко начинается с середины страницы.

### 2. Скользящее окно

Если probe длиной 500 не дал совпадения, пробовать сдвиги:
- offset in [0, 50, 100, 150, 200, 300]
- window in [200, 300, 500]

**Зачем:** первые 200 символов stripped-текста часто содержат номер подпункта (4 2, 8 1, 29 1) или сноску ((Подпункт утратил силу...)), которых нет в PDF. Уникальное содержание начинается с позиции 50-150.

### 3. Нормализовать \|

Добавить в _normalize():
```python
text = re.sub(r'\\\|', ' ', text)   # артефакты таблиц -> пробел
```

366 чанков содержат этот артефакт. Без этой нормализации точное совпадение принципиально невозможно для табличных данных.

### 4. Для истинных расхождений

~1 случай на 828 (вероятно, даже меньше) - embedding-поиск по всему тексту чанка, без exact-match.
