### Причины множественных совпадений

1. **Повторяющиеся фрагменты** — одинаковый текст (номера, ссылки) на нескольких страницах.
2. **Шаблонный текст** — стандартные формулировки (льготы, исключения) в разных частях документа.
3. **Дублирование структуры** — заголовки разделов/глав повторяются на каждой странице раздела.
4. **Перекрёстные ссылки** — ссылки на другие статьи, которые встречаются многократно.

Для устранения неоднозначности: контекстный поиск (соседние строки) или embedding-поиск.

## 5. Выводы и рекомендации

### Подтверждённые данные

1. **502 null-записей (23.4%)** — PDF без текстового слоя. 
   26 документов не содержат извлекаемого текста (сканы без OCR). 
   **Это коренная причина.**
2. **470 (21.9%)** — редакционные примечания, которых нет в PDF.
3. **333 (15.5%)** — самоотсылки ('настоящий Федеральный закон'), сформулированные в PDF иначе.
4. **8 (0.4%)** — короткие фрагменты (< 50 символов) — не маппятся по дизайну.
5. **828 (38.6%)** — прочие расхождения текста чанка и PDF. 
   Требуют ручного анализа конкретных документов.

### Рекомендуемые действия

1. **OCR для 26 PDF** (Tesseract/PaddleOCR). Без этого ~29% чанков никогда не будут сопоставлены.
2. **Фильтр редакционных примечаний** — при загрузке в Qdrant удалять или помечать строки с '(в редакции…)' и '(с учетом…)'.
   Потенциально улучшит покрытие на 470 записей (~21.9%).
3. **Замена 'настоящий Федеральный закон'** на название документа из префикса чанка [doc_display].
4. **Контекстный поиск для ambiguous** — увеличить probe или использовать соседние чанки.
