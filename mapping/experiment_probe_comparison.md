# Эксперимент: сравнение стратегий probe для категории «Прочие расхождения» (828 чанков)

**Дата:** октябрь 2026
**Метод:** точное вхождение (exact match) нормализованного probe в нормализованный текст страниц PDF.

**Важно:** baseline (probe_200) в эксперименте отличается от текущего `build_page_mapping.py`:
в эксперименте `strip_prefix()` применяется ДО обрезания до 200 символов, а не после.
Это даёт более длинный probe (200 символов полезного текста вместо до 200 минус длина префикса).
Результаты — верхняя оценка; реальный прирост в текущем коде может быть на 5-10% ниже.

## 2. Ключевое наблюдение: более длинный probe НЕ помогает

probe_500 и probe_800 находят **меньше** чанков, чем probe_200, и **0** новых:

| Стратегия | Найдено | Отношение к probe_200 |
|-----------|--------:|:---------------------|
| probe_200 | 346 | 100% (база) |
| probe_500 | 247 | 71.4% (найдено 247 из тех же 346, 99 потеряно) |
| probe_800 | 190 | 54.9% (найдено 190 из тех же 346, 156 потеряно) |

**Причина:** чем длиннее probe, тем больше шанс, что какой-то символ в хвосте отличается от PDF.
Типовые расхождения: номер подпункта (`4 2)`, `8 1)`), артефакты `\|`, OCR-ошибки, разный перенос строк.

**Вывод:** простое увеличение probe ухудшает результат. Рабочий подход — скользящее окно (сдвиг начала
probe мимо «шумного» участка).

---

## 3. Анализ стратегий

### 3.1. Скользящее окно (sliding_200+50) — главный результат

- **Найдено:** 724/828 (87.4%), из них **380 новых** vs baseline
- **Неоднозначных:** 70 (9.7% от найденных)
- **Механизм:** probe=200 со сдвигами 50, 100, 150, 200, 250, 300; первое совпадение фиксируется

**Почему работает:** первые 50-150 символов stripped-текста заняты «шумом»:
  - `4 2)` — номер подпункта, в PDF отсутствует
  - `7 3. Текст...` — номер пункта, в PDF записан иначе
  - `(Подпункт утратил силу...)` — сноска, в PDF её нет

Сдвиг на 50+ символов пропускает шум и находит уникальное содержание.

### 3.2. Нормализация `\|` (probe_500_norm_pipe)

- **Найдено:** 303/828, из них **56 новых** vs baseline
- **Потеряно 99** из 346 (из-за probe=500, не из-за `\|`)
- **Чистый эффект в комбинации:** +8 табличных чанков (оклады, ставки, перечни)

40 чанков (4.8%) имеют разные номера страниц от разных стратегий.

### Проверенные случаи (извлечение текста из PDF и поиск точного вхождения):

| chunk_id | Стратегии (стр.) | Результат проверки |

| 117-fz_st162_3_p1 | probe_200: 104 / sliding: 813 | **Обе правы.** Текст найден на стр. 104, 813, 875, 1184 — множественное вхождение |

### Итог по 40 конфликтам:

| Тип | Кол-во | Пояснение |
|-----|:------:|-----------|
| Множественные вхождения | ~25 | Текст на нескольких страницах — обе стратегии корректны |
| Разные offset → тот же текст | ~13 | Разные offset дают совпадение на разных страницах с одинаковым текстом |
| Off-by-one (соседняя страница) | ~2 | Разрыв текста между страницами → одна стратегия ошибается на 1 страницу |

**Вывод:** ~0.24% ложных срабатываний (2 из 828). Допустимо для автоматического маппинга.

## 5. Оставшиеся null (74 чанка, 8.9%)

Не найдены ни одной стратегией. Причины:

| Причина | Оценка |
|---------|:------:|
| Текст принципиально отсутствует в PDF | ~1 |
| PDF-артефакты (нестандартные символы, разрывы слов) | ~20-30 |
| Слишком специфичный контент (таблицы) | ~30-40 |
| Некорректная сегментация чанка | ~10 |

Для этих чанков необходим embedding-поиск.

## 7. Рекомендация

### Перенести в build_page_mapping.py:

1. **Скользящее окно (sliding_200+50): ДА, обязательно**
   - Эффект: +380 новых сопоставлений (+109.8% к baseline)
   - Реализация: offset=[0, 50, 100, 150, 200, 250, 300], probe=stripped[offset:offset+200],
     брать первое совпадение
   - Риски: ~0.24% off-by-one (2 из 828) — допустимо

2. **Нормализация `\|`: ДА, рекомендуется**
   - Эффект: +8 табличных чанков
   - Безопасно: артефакт парсера

3. **Увеличение probe до 500/800: НЕТ**
   - Ухудшает результат. Заменить на sliding window.

### Оценка общего эффекта:

- Текущий null: 2146 (39.4% от 5446)
- После sliding + norm_pipe: 2146 - 410 = 1736 (31.9%)
- После всех категорий: ~584 (10.7%)

## 8. Ограничения эксперимента

1. **Смещение:** тестировались только «Прочие» (828). Для других категорий результат может отличаться.
2. **Одноуровневый sliding:** фиксированная длина 200 при любом offset.
3. **Нормализация `\|`:** тестировалась только с probe=500, не с probe=200+sliding.
4. **Порядок offset:** первое совпадение (offset=0 приоритетнее). Альтернатива: брать совпадение
   с наибольшим offset (самое уникальное) или проверять все и отсеивать неоднозначные.
