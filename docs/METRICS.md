# Метрики RAG-поиска — краткая выжимка

Цель исследования — выбрать оптимальную архитектуру поиска для двух типов запросов: **USER** (абстрактные, смысловые вопросы) и **EXACT** (точные реквизиты статей, номера НПА). Замеры проводились на двух чистых датасетах (76 USER и 145 EXACT запросов) с корпусом 5446 чанков в Qdrant.

**Результат:** для USER-запросов лучший режим — чистый DENSE на эмбеддингах FRIDA (Sber RoBERTa, 1536 dim): **Hit@5 = 88.1 %** при ~50 мс. Для EXACT-запросов необходим HYBRID 0.5/0.5 + реранкер **BAAI/bge-m3**: **Hit@5 = 86.2 %** (прирост +12.4 % к чистому DENSE). Адаптивный классификатор (`app/rag/classifier.py`) автоматически переключает режимы под тип запроса.

В поиске альтернативы FRIDA тестировалась multilingual-e5-large (1024 dim): она быстрее (в 1.7–2.0 раза) и лучше ранжирует при найденном ответе (MRR выше на USER), но заметно уступает FRIDA по полноте поиска (Recall). Для юридических консультаций критична полнота, поэтому **FRIDA остаётся основной моделью эмбеддингов**.
